## Fixes, in order
1. **Kill the hydration mismatch** behind the red "1 Issue" badge. Something in the hero stage or the header renders differently on server and client. The likely candidates are random or time-based initial state in the request lane, or the stage's full-bleed/inset class. Render the same first frame on the server and on the client.
2. **The hero stage must never change frame.** Server-render it already inset (rounded card inside the 24px gutter), including under reduced motion. The pause button must sit inside the card at 16px from the right edge at all sizes. Under reduced motion show the resolved final frame: the request passed, X-Org-Id struck through, the "payments-api X-Org-Id ✓" chip landed on the right.
3. **Fill the hero stage's empty right half.** Start the loop with a card already in flight at t0, so frame 0 is never empty lanes, and keep one landed result chip resting on the right side all the time. On phone, crop the stage so the request card and the gateway line are both inside the first 812px, and move the vertical "GATEWAY" label 24px left of the pause button.
4. **Give "Nothing downstream has to ask who is calling" an object, or fold it in.** Make the h2 the moment: it grows from 44px towards 64px as it crosses centre, then settles. Put the hero's request lane, shrunk to a single line, under it, so one header is visibly stripped and written back as you scroll. Cut that screen's height from ~801px to about 60svh so it does not read as a blank slide.
5. **Remove the "01 / 06" eyebrow from above each chapter heading.** Move it below the heading as a caption, or put it in the panel's title bar beside "api.hanzo.ai", where "01" already exists, so the duplicate counter can go. Do the same for the "api /v1/gateway" pill above the Paste-and-ship code block: put it inside the code block's header bar.
6. **Phone: one solid fill per viewport.** Turn the header "Try Hanzo" quiet (outline) while the hero "Read the docs" or the closing "Read the docs" is in view, as desktop already does.
7. **Phone closing Band: clear the Sigil art off the text.** Push the art below the asks, or behind them at about 30% of its stroke strength, kept right of x=60%. It must never cross the h2 or the chips.
8. **Primary hover colour.** Use a deck value, #262626 or #171717, not #2c2c2e. Give the secondary a real hover: a background of #f5f5f5, or the ink border at 100%, not 8% to 18%.
9. **Related row hover.** On hover or focus, the arrow nudges 4px and a 1px ink underline draws under the title over 300 ms. Set "Gateway docs →" the same way as DNS, Service Mesh and Nodes, with the arrow on the right edge.
10. **Fix the missing space** in "Authorization: Bearer JWT" and "Bearer API key" in the Forge "You send" row.
11. **Touch targets.** On phone, give "Deploy to Cloud" and "Self-host" a 44px min-height hit area, and "Open in the console" 44px too. Related links are 39px wide; pad them to 44.
12. **Arrival.** Cut the h1 in by line mask, with the lede and the two asks following on the 60 ms stagger, instead of the h1 sitting alone at t0 while the rest pops in.
13. **Scale rhythm across the page.** Pick one thing per screen to be big. Two candidates: the chapter panel's figure ("JWKS ✓", "429 · Retry-After") at 64px while active and 44px at rest, and the Forge result panel. Keep everything else at 26/17/14.

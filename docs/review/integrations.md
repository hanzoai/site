Total hold at most 700 ms, with the destination painted under it by 600 ms. On phone, never show a blank white frame for more than 250 ms (use the 250 ms crossfade fallback). Measure: from click to visible destination h1 under 800 ms, and no frame with an overlay title off the h1 after 700 ms. (The engine is shared; file the request if it is engine-side, and fix the title or target hand-off on this page.)
2. **Real logos for every tool, 19 of 19.** Mirror the real marks for OpenAI, LlamaIndex, AutoGen, Continue.dev and DSPy into `public/`, in mono ink like the rest. Zero two-letter monograms, in both the ring and the grid.
3. **Make the grid a catalogue, not 19 grey boxes.** Fill the last row with no hole: 19 tiles at 4 columns leaves 3, so let one tile span or vary the widths so every row ends flush. Give tiles with no description a real object (the tool's own one-line install command or a large mark) so no tile is empty above its hairline. Add a list-level entrance (one stagger, 60 ms) and real gliding motion on the filter pill (300 ms ease-emphasis).
4. **Phone: one solid ask.** At 375 the header ask must be quiet (outline) while the hero "Get an API key" is in view, then swap to "Get an API key" as desktop does. Desktop: start the header ask outlined, with no solid-to-outline fade at 1.4 s on load. Measure: exactly 1 element with a #0a0a0a fill on screen in every frame of the 8 s idle capture at both sizes.
5. **One thing in, one thing out.** Tie the hero ring to scroll as the code block arrives (it shrinks or docks into the 19 in the sub-bar and the code rises 40 px over it), so the page stops reading as a document. Keep scroll-linked motion at half or less of the page's motion.

7. **Phone code block:** stop `base_url` from wrapping its comma onto its own line. Use horizontal scroll inside the labelled region, or a 13 px font at 375. Put Copy on the tab row instead of its own row.

9. **Cookie card (shared chrome):** on desktop it sits over the grid's bottom row. Keep it out of the content column or make it a 1-line bar, and keep it at 220 px or less on phone (now 217 px).

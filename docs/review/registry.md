## Fixes to reach 8

1. **Make the pinned run a moment, not a list.** Grow the plate stack to the hero of each step (at least 2x its present 190px on desktop) and let each fact act visibly on it: the token dropping and locking, the org plate turning ink, the signature and attestation docking, a layer sliding out with storage visibly shrinking, people folding into one account. Cut the grey row lists to one short caption per step, or drop them where the stack already says it. The page then shows one object per screen instead of an object plus a table.
2. **Stop repeating the hero in step 01.** The client / 401 / token / signature / push rows are the hero's log again. Show that fact only on the stack (the token descends and the stack accepts it), or reuse the hero's own window as a scrubbed miniature, not a second list.
3. **Shorten the pin.** Six facts over about 5.4 screens is too long for this much change. Bring `per` down so the run takes about 3 to 3.5 screens, or tie each step to a clear change of the stack so the scroll feels earned.
4. **Fix the dark-room ledger's double rule.** Keep one hairline: drop `.rg-swap`'s `border-top` and padding, or `.rg-swap-t`'s `border-top`, so the empty band between them disappears at both sizes. Trim the trailing black below the ledger.
5. **Close the dead white.** Fill the empty lower 200px of the hero's registry pane (let the list sit lower, or end the pane where its content ends). Tighten the gaps after the console note and before "Get started", which are each about 250px of nothing at 1470x801.
6. **Break the cloud template once.** Give Registry one structural move its siblings lack, for example: the related "Builds: Source to signed image" card opens into its page by Morph, or the console section is replaced by the hero window continuing (pulling the signed image). Neighbours should not read in the same six-block order.
7. **Settle the section heads to rest size.** Use about 26 to 32px for the pinned and dark-room h2s unless that heading is the screen's single moment, so the push, the stack and /v2/ are the big things.

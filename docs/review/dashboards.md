2. **Say Monitors once.** Either drop chapter 02's sentence and let the Watch section be where Monitors is explained (the board's chapter 02 shows only the head and the alert chart), or fold the drag interactive into the board's chapter 02 so it plays in the pin.
3. **Lift the hero object into the first screen at 1470x801.** Raise the panel so the chart's baseline is visible (the h1 can sit level with the lede rather than below it), so the first screen sells with the drawn chart, not just the query.
4. **Give the second half one more moment.** The four-word strip and "Start from a trace" read like a document. Let "Start from a trace" be a stage: the example console's dashboards row opening into the hero's widget (card to page), or the four words resolving from the board's six panels.

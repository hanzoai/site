## Fixes (ordered, most important first)
- **Chapter 5 token card breaks the path mid-word.** "acme/prod" wraps to "acme/pro" + "d" inside the black TOKEN card at 1470 (the value column is too narrow). Give the value `white-space: nowrap` / `overflow-wrap: normal` with a min-width in `ch`, or widen the card. Check the same value at 375 and in every scene (chapter 3's "app or / site" chips too).
- **Break the sameness of the pinned stage.** Six identical 660px grey cards in a 5,263px pin read as a document. Let the scene object carry the moment: scale the active scene from about 0.94 to 1 as it arrives and settle it, or let one scene (05, the token travelling across the edge) move across the split. Cut the pin length so each chapter is about 0.7 screen, not 0.9.
- **Close the dead gap between hero and statement.** About 250px of white sits above "Hanzo Authz reads a token…" at 1470 (h2 top 1079, hero window ends near 830). Start the statement drawing ("CAN" end) in its final state in the HTML, and draw it from there, so the right end is never a blank label.
- **Desktop hero composition.** The lede and asks sit 70px above the h1 baseline on the right, so the first screen reads as two misaligned blocks. Bottom-align the right column to the h1 baseline (MASTER 8/5 split, "aligned to the bottom"), and pull the window up so the decision panel's last line ("acme/prod prefixes acme/prod/web") sits above 801.
- **Make the big answer one moment, not three.** 64px Air "true/false" appears in the hero, the statement and the delegation card. Keep the hero at 64, and set the statement and delegation answers at 44 or 32 so the scale has rhythm.
- **Fill the hover gaps.** "View on GitHub" (move the arrow 3px or underline), the expiry switch (thumb or track darkens on hover) and the hero location rows (border to #a3a3a3 like the callers) change nothing on hover today.
- **Chapter 2 heading wrap.** "Nothing on the decision path does I/O" breaks into three ragged lines at 26px. Widen the measure to about 18 characters per line, or use `text-wrap: balance` on that h3 so it sets as two lines.

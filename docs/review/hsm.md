# /hsm — James-eye review
7 Nov, walked at 1470x801 and 375x812 (isMobile, hasTouch) in Playwright Chromium: frames at 0/1/3 s untouched, wheel-scrolled a screen at a time with 1.5 s dwell, hovered/pressed every control in main on desktop, tapped tabs and Copy on phone, checked 320px overflow and reduced motion.

Verdict: 6/10

First complaint: "The black chapter bit is lovely, that's the feeling I want. Then you put a little number label on top of every headline, and straight after it three identical grey boxes in a row with big text, and tabs that don't change anything when I click them. And why is there a whole screen of white nothing?"

## The 11 answers
1. **Sells in 5 s, moves in 1 s?** Mostly. The h1 cuts in by line mask and the hero stack cycles its own state (the caption steps from AWS KMS to Azure Key Vault) without input. But at 0 s the hero card is drawn wider, bleeding past the right edge (x 603 to 1470), then jumps in to 628 to 1446 within the first second. On phone the first frame shows only the h1; the lede and button pop in later.
2. **One in, one out?** Yes in the pinned black chapter (01 to 06, one slab lights per step, text swaps). That is the best thing on the page. After it the page turns into a document: Paste and ship, then Pick your module, then Get HSM, each surrounded by 250 to 350px of empty white.
3. **Real object in every section?** Hero: yes (iso key stack). Chapters: yes. Paste and ship: a single-line code block, thin. Pick your module: no object, just three text tiles. Get HSM: decorative contour lines with a large empty lower half.
4. **One ask, nothing floating, rhythm of scale?** The ask is not consistent. The desktop header swaps from "Try Hanzo" to a solid "View on GitHub" once you scroll, but the phone header keeps "Try Hanzo". At the close, the solid header "View on GitHub" and the solid closing "View on GitHub" are on screen together, so there are two solid fills. Scale is mostly fine (h1 52, h2 26/32/44), but the module tiles set 21px body text in three equal boxes, so that screen is all one size.
5. **Every hover and press answers?** No. The primary press scales to 0.98 (good), but its hover only darkens to rgb(44,44,46), which is #2c2c2e, a blue-tinted grey that is not on the deck ramp. The six chapter dots, Copy, the "hanzoai" pill and the license pill show no hover change. "Deploy to Cloud" shows no measurable change. Copy grows wider when it switches to "Copied". The tabs answer visually, but AWS KMS, Azure Key Vault and Google Cloud KMS show byte-identical panels, so 3 of 5 clicks change nothing.
6. **Overlap, font swap, layout shift?** Measured CLS is 0.0002, but the hero card visibly changes width in the first second. On the first load at both sizes the Next.js "1 Issue" badge appeared (a hydration attribute mismatch: "server rendered HTML didn't match the client properties"). It did not repeat on clean reloads, so it is intermittent or a first-compile effect, but it needs checking. On phone the agent-prompt line is cut at "use H" with no scroll cue, and the tabs wrap into a 3-row blob. No horizontal scroll at 375 or 320.
7. **Which reference, and is its motion there?** apple.com: the pinned scrubbed scene with one panel changing is genuinely there and well paced. The anthropic or chatgpt-enterprise calm is not carried through the bottom half.
8. **Different from neighbours?** The isometric key-stack object and the black pinned stage give it its own hero medium. The bottom three sections are generic kit layout.
9. **18 parts?** Not verifiable from the render alone. Visibly missing are a proof strip before the close and any objection answer near the ask. The closing Band is present ("Get HSM").
10. **Banned tells?** Yes, two, and either one fails the page: (a) a "01 / 06" mono label sits directly above every chapter h2 (label above a headline); (b) three equal boxes in a row (THE KEY / THRESHOLD SIGNING / ML-DSA-65). Also an off-ramp hover colour (#2c2c2e), and a "WHAT IT IS" label floating orphaned under the dots.
11. **Copy untouched?** parity.py reports /hsm OK, text 28/28, links 2/2.

## Fixes, in order
1. **Chapter labels:** move "01 / 06" from above each chapter h2 to below the body text, next to the dots as the step caption (12px Zen Mono, white 55%). Nothing sits above the h2. Put "WHAT IT IS" in the same caption row, or drop it as a visible label if it is a section name.
2. **Pick your module tiles:** kill the three equal boxes. Make the tab panel one object: a single wide sheet split 8/5, with THE KEY as the large statement on the left (21px) and THRESHOLD SIGNING and ML-DSA-65 as smaller hairline-divided rows on the right (16px). Or render it as a spec list with 1px rows. Body text in it goes to 16 to 17px; only one thing is big.
3. **Dead tabs:** when the copy for AWS, Azure and Google is identical, the tab has to change something visible: the module name in the panel header, the iso stack's bottom slab label, or a one-line config snippet (`provider: aws-kms`, built only from the tab's own label). Crossfade the panel (150 ms) so the click reads.
4. **Dead white:** cut the 300+px empty bands above "Pick your module" and around "Paste and ship" to the section token. Pair Paste and ship with Pick your module in one room (the prompt as the object, the tabs below it), and let the Get HSM contour object fill its section rather than trailing into white.
5. **One ask:** keep a single header ask label across sizes (desktop and phone must match), and never show the solid header ask and the solid closing "View on GitHub" on screen together. When the closing Band is in view, the header ask goes quiet.
6. **Hero load jump:** fix the hero card's first-paint width so it does not render 1470-wide and then snap to 1446. Set its final box in SSR CSS. On phone, render the lede and button in the first frame (no opacity:0 waiting for JS).
7. **Hydration mismatch:** find the client attribute that differs from the server (likely a random or window-dependent value in the hero/stack or the ask swap) and make it deterministic, so the "1 Issue" badge never appears on first load.
8. **Hovers:** primary hover goes to a deck value (#262626 or #171717), not #2c2c2e. Give the chapter dots a hover (grow to 10px plus a step-name tip), give Copy a hover fill, give "Deploy to Cloud" an arrow nudge (4px), and give the license and GitHub pills a hover state. Fix Copy's width so it does not grow when it says Copied.
9. **Phone tabs:** make the tablist a single horizontal scroll rail (scroll-snap, 16% peek), not a 3-row wrapped pill. Make the agent-prompt line wrap, or add a visible fade-edge scroll cue so "use H" is not just cut.
10. **Closing proof:** add the page's own proof line (the Apache-2.0 license and GitHub pills already exist) as a quiet strip directly above the "Get HSM" band, so the close is proof, then ask, then footer.

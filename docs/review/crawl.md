## What works
- **The hero is alive within 1 s.** The URL types itself into the `POST /v1/crawl` bar (`https://example.com/docs,` at 0.75 s), the Markdown panel streams `# API / ## Authentication / - [Keys]…` line by line, and the path tabs cycle on their own (`/docs/api` to `/blog/launch` at about 4.5 s). There is a 44px pause control beside the meta line. It is the product doing its job, scripted from the page's own words.
- **The pinned "Three steps, and a boundary" scene is the signature, and it earns it.** It is about 5,070px tall and pins a grey stage. Six progress segments fill with scroll, the chapter list on the left steps from grey to ink, and each chapter gets its own object: a page wireframe with the `content` box lifted out; `fetch + parse` against a black `Headless Chromium` panel; Markdown plus title and description metadata; a site tree with `169.254.169.254 refused`; `302 refused at the hop`; then HTTP and MCP cards. One thing comes in as one goes out. This is the Apple pinned-stage idea done properly.
- **The pricing slider answers.** The `50,000` figure (about 64px, Air) moves to `500,000`, the "Scale · $499/mo · 25 concurrent crawlers" line updates, and the matching plan column takes the ink outline. ArrowRight works, and `aria-valuetext` reads "500,000 pages/month".
- **Copy confirms.** Copy writes exactly the displayed agent prompt to the clipboard, and the label flips to "Copied" within 120 ms.
- **Clean:** no hue anywhere (computed-colour scan found 0 chromatic values outside media). The phone has no horizontal scroll at 375 or 320. CLS was 0.0004. The h1 box held steady at x159 y335, 659×53, from 0.75 s on, so there is no font swap. Parity is `text 108/108, links 14/14`. Under reduced motion, 0 animations were running after 3 s.
- **Rhythm is mostly right:** h1 at 52px, section heads at 26px, one 64px figure per screen, body at 14 to 16px, and the closing "Get Crawl" band at 44px on a graphite room, with the header flipping to a dark style over it.
- **The phone is its own composition.** The pinned scene becomes a stage with a pause button and `01 to 06` chips (44px each). Plan cards stack one per screen. The h1, lede and primary sit in the top 234px, so the ask is above the fold at 375×667.

Make it one object: e.g. a pinned list where each capability name is a 44px row and hovering/focusing a row shows a small product render (inspector crop for Live DOM, a failing request for Visual QA, two tabs side by side for Cross-tab), or an asymmetric 8/5 with one large live render and the rest as hairline rows. No icon-on-grey tile, no paragraph under every tile.
- De-duplicate: "Wildcard site allowlists & blocklists" and "Password manager guardrails" already live in the black room; drop those two from the bento (or drop the bento copies and link to the room) so each idea appears once.

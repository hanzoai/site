## Fixes, in order
1. **Stop showing the same pipeline four times.** Keep the hero graph as the one full pipeline. Give the pinned scene a different panel per feature, built from its own copy: The library is a palette of the component types Hanzo lists; Open any node is a node opened to its Python class; Step through it is the playground; Multi-agent is several agents on one canvas; Publish it three ways is the three outputs (REST, JSON, MCP); Keys stay out is a variable referenced by name. Then either drop the separate "Step through it" black room or make it the only place the playground appears, and take the playground card out of the hero.
2. **Kill the 16px bob in the step-through panel.** Reserve the "returned" row at the chip's height (fixed min-height) so "…" and the chip occupy the same box. Do the same for the hero playground card (6px).
3. **Replace the invented demo data** with strings from Hanzo's own copy, or add them to `content/ui-strings.json` as a listed copy question for James. Remove "running" and "passing to text splitter" unless they come from ui-strings.
4. **Remove the duplicated "Step through it" heading.** The black room's h2 reuses the pinned h3 word for word: use one heading or the other.
5. **Close the dead air:** about 250px above "Get Flow", about 160px of empty graphite after the step panel, and the stranded "The canvas is not the ceiling" h2, which should sit closer to its stage (the next section should peek within 56px).
6. **Hero node hover must say something:** show the node's out value or lift and outline it. A 0.1-to-0.4 border tint is not an answer.
7. **Hero playground card:** give the pause button its own slot so it stops crowding "01 / 06", and remove the stray top hairline.
8. **Phone polish:** a readable visited state on the step tabs (it is grey on grey now); connector heads that don't fuse into a blob between stacked nodes; no mid-word break in nodes at 320 ("documen/ts"). Wrap at the space or let the node grow.
9. **Step tabs:** keep every tab to one line (or reserve two lines for all) so "Document loader" stops being taller than the rest.
10. **Add real Flow media** if Hanzo has any (a screenshot or film of the actual canvas) to the pinned scene or the open card, so the page isn't only drawn diagrams.

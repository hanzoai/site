## The 11 answers
1. **Sells in 5 s, moves within 1 s?** Yes on desktop. The h1 is there at 0 s, and by 1 s the handler.js file is typing itself into a cluster panel: triggers light up, replicas fill node rows, and it loops with a pause button. It's the right object for "Functions that run on Kubernetes." But the hero card runs off the right edge of the viewport (it ends at x 1503 on a 1470 screen) with a flat, cut edge, so it reads as cropped, not as a deliberate bleed. On the phone the hero object sits below the fold, under the CTA, the caption and the pause button.
2. **One in, one out, or a document?** Mostly one in, one out. "What you get" is a pinned stage: one panel changes through 01–06 with a progress rule. Use cases are a scroll-driven list where the panel swaps. Then the untitled grey configurator room breaks the rhythm. It repeats the runtimes, the four triggers, NVIDIA GPU and Blue/green/canary, which the hero and the stage already showed, and it re-lists three of the page's own sentences. The spec strip after the use cases does the same again. That part reads like a document.

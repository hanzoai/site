Start each chapter's demo from a filled first frame (bubble, code block, file chips already set) and give each chapter enough scroll length that its demo ends before the next one starts (Search and code must reach "14 passed"). 7. **Enso art card, desktop:** remove the big soft drop shadow (only floating things take a shadow); it leaves a grey smudge under the header near the Band. Model tiles: flat fill or outline, not both.

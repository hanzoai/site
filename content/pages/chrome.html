What it is

Real-time browser intelligence under enterprise control

Stop copying and pasting screenshots, stack traces, and table rows between tabs.

01

Acts in your live tabs

Navigates pages, fills forms, clicks controls, and extracts structured data from any web application you are already signed into.

02

Bridges browser to IDE & CLI

Streams live DOM styles, console logs, and network timings straight to Hanzo Dev, VS Code, JetBrains, and Code Channels over MCP.

03

Zero-trust admin controls

Organization owners toggle extension access, block password manager interaction, and enforce domain allowlists or blocklists across every seat.

Capabilities

Built for engineering, design, and operations

Live DOM & CSS inspection

Select any element on staging or production to inspect computed tokens, contrast ratios, and component props, then generate the exact patch.

Visual QA & bug reproduction

Ask Hanzo in Chrome to reproduce a reported bug, capture the failing network request, and post a Canvas summary to your code channel.

Cross-tab synthesis

Compare specifications in one tab against a live deployment or pull request in another and flag every discrepancy.

Password manager guardrails

Keep credential vaults isolated by default; organization admins explicitly control whether agents can interact with password managers.

Wildcard site allowlists & blocklists

Configure Allow All Sites with sensitive exclusions or Block All Sites with approved internal domains in Organization Settings.

Direct handoff to Hanzo Bot & Team

Start a task in your Chrome side panel and hand long-running background execution to a cloud resident bot or Slack code channel.

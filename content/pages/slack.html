What can Hanzo Tag see in Slack?
Hanzo only reads messages in public or private channels where @Hanzo has been added, and only inspects thread context when someone explicitly tags @Hanzo or when scheduled channel work executes.
Does Hanzo respond only when someone tags it?
Yes. In channels, Hanzo only responds when someone mentions @Hanzo in a message or thread, or when a scheduled task configured by your team posts to that channel.
Does Hanzo Tag use my personal accounts to do its work?
No. Hanzo Tag uses organization-scoped connectors, GitHub installations, and federated workload identities (WIMSE) configured by your organization owners rather than personal member accounts.
Can Hanzo Tag use the MCP connectors we have already set up in Hanzo?
Yes. Any organization-level MCP connector enabled under Plugins & connectors can be granted to Hanzo Tag for channel queries, incident triage, and code channel workflows.
How is Hanzo Tag billed?
Hanzo Tag is available on Team and Enterprise plans and is billed by usage — you pay for the work Hanzo does in channels, not per Slack seat. Direct messages to Hanzo count against the individual member’s own Hanzo plan limits.
Is our Slack data used to train models?
No. Conversations with Hanzo Tag are never used to train models, and channel activity is isolated from individual members’ personal Hanzo chat history.

Laboratory Infrastructure

The cleanroom execution environment

Autonomous agents cannot be evaluated on unconstrained local machines. Every student is provisioned an isolated execution pod with strict kernel virtualization and zero-copy IPC.

LABORATORY TERMINAL · ISOLATED RUNSC BOUNDARY
Real-time terminal feedback: students inspect agent AST diffs, Cap’n Proto trace records, and micro-USD budget meters.
Hanzo Visor (`runsc`) User-Space Kernel IsolationEvery agent turn runs inside an unprivileged sandbox pod with virtualized syscalls, seccomp filtering, and read-only host mounts.
Zero-Copy ZAP IPC ProtocolMulti-agent communication traverses Cap’n Proto zero-copy serialization over Unix domain sockets, reducing message dispatch latency from 180ms to < 2ms.
Zen 6 High-Throughput Model ServingAccess quantized GGUF/AWQ builds of Zen 6 (27.3B) and Zen 6 Flash with continuous token streaming, structured JSON tool schemas, and KV-cache reuse.
Micro-USD Financial GovernanceEvery test execution is bound to an exact integer micro-USD budget ceiling ($0.50 per defect). Exceeding the ceiling triggers in-band refusal and automatic grading failure.

Evaluation Standards

Grading Rubric & Automated Evaluation Policy

To earn the Hanzo Certified Agentic Coding Engineer (HACE) credential, candidates must satisfy rigorous machine-evaluated benchmarks. All grading is conducted via synthetic fault injection in isolated cleanrooms.

40%Test Suite Pass Rate100% of pre-existing unit test suites and student-synthesized reproduction tests must pass with exit code 0.
20%AST & Type CleanlinessPatches must pass strict AST verification, linters, and typecheckers without introducing formatting errors or dead imports.
20%Micro-USD Budget CeilingsThe agent must resolve each defect within a strict 500,000 micro-USD ($0.50) ceiling. Exceeding the ceiling triggers instant failure.
20%Telemetry & Audit FidelityFull Cap’n Proto trace records, tool invocation timestamps, and Kai state probabilities must be emitted to ClickHouse O11y.
The Cleanroom Fault-Injection Policy
To prevent students from hardcoding solutions to known SWE-bench issue IDs, the Hanzo Grader Pod executes synthetic fault injections: renaming test assertions, injecting subtle dependency regressions, and scrambling directory paths during test execution. Passing requires a truly generalized autonomous reasoning and repair harness.

Infrastructure delta

The 60% delta above is a simplified default and a user-controlled assumption, not a universal benchmark. The egress anchor is real — DigitalOcean at $0.01/GiB against an AWS example at $0.09/GB — but it supports an egress comparison; it does not prove 60% for every workload. A full model would price provider, compute, GPU, database, storage, egress, observability, support, existing commitments, target Hanzo cost and migration overlap separately.

Glue engineering

The seams a vendor stack requires someone to own: auth bridges, webhooks, data sync, billing reconciliation, entitlements, audit exports, pipelines, vendor o11y, incident routing, schema transforms, secret rotation, API migrations, identity lifecycle, model fallbacks, security reviews. The default of 1.5 FTE at $220k fully loaded is conservative for a 30+ vendor estate, and 0.5 FTE of platform operations is subtracted on the other side.

Do not say Hanzo eliminates engineering. Hanzo redirects it from vendor seams to product.

The bill is the cheap half

Everything above prices what you stop paying. It ignores what you would have to build to own the whole thing yourself. Public anchors: Auth0 acquired for ~$6.5B · Datadog ~$1.55B of 2025 R&D · Zapier 800+ people and 9,000+ integrations. These are not additive valuations; they show each category is a substantial engineering domain. A replacement-cost study of the full repository estate is under analysis — no number will appear here until that report lands.

Exclusions — what this model never counts

Card interchange and network fees (the payment row counts PSP markup only) · frontier model pass-through, unless the workload is routed, distilled or self-hosted · deep vertical software (clinical, CAD, EDA, airline operations, industrial control, scientific instruments, jurisdiction-specific record systems) · migration coexistence, where both stacks run at once · retained vendors, since every row is independently deselectable.

Market context

Okta 2026: 98 applications on average, 259 at companies with 2,000+ employees, 72 below that. Zylo 2026 SaaS Management Index: a median of $9,455 of SaaS spend per employee, with 36% of licenses unused. The $613k software default at the reference deployment works out to $6,130 per employee — below Zylo’s enterprise-skewed median, so the model is conservative relative to the benchmark. None of this implies all SaaS spend is recoverable.

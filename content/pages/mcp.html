Get started

One config block

Use the --package= form for local stdio, or point any MCP client directly at https://api.hanzo.ai/v1/mcp over streamable HTTP.

json
// .mcp.json — add Hanzo MCP to any MCP client
{
  "mcpServers": {
    "hanzo": {
      "command": "npx",
      "args": ["-y", "hanzo", "mcp"]
    }
  }
}

// Or install the whole native stack once and run it yourself:
//   npm i -g hanzo
//   hanzo mcp              # stdio; the binary downloads on first run
//   hanzo mcp -t sse       # or over HTTP
